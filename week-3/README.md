# Week 3: Your First Pull Request

## Learning Objectives
- Understand Fork and Pull Request workflow
- Make your first open source contribution
- Learn PR etiquette and best practices

## Easy Tasks
1. **Fork a Beginner-Friendly Repository**:
   - Visit [First Contributions](https://github.com/firstcontributions/first-contributions)
   - Click "Fork" button (top right)
   - Clone YOUR fork to your computer

2. **Make Your First Contribution**:
   - Follow the repository's CONTRIBUTING.md
   - Add your name to the contributors list
   - Commit with a clear message
   - Push to your fork

3. **Create Pull Request**:
   - Go to your fork on GitHub
   - Click "Pull Request" button
   - Write a clear title and description
   - Submit the PR!

4. **Explore More Beginner Projects**:
   - Visit [Good First Issue](https://goodfirstissue.dev/)
   - Find projects in your favorite language
   - Star interesting repositories

5. **Document Your PR**: Add the PR link to your journal.md

## LeetCode Problems (Easy)

### Problem 1: Merge Two Sorted Lists
**LeetCode #21** | **Difficulty**: Easy

**Link**: https://leetcode.com/problems/merge-two-sorted-lists/

**Description**: Merge two sorted linked lists into one sorted list.

**Example**:
```
Input: list1 = [1,2,4], list2 = [1,3,4]
Output: [1,1,2,3,4,4]
```

**Topics**: Linked List, Recursion

---

### Problem 2: Remove Duplicates from Sorted Array
**LeetCode #26** | **Difficulty**: Easy

**Link**: https://leetcode.com/problems/remove-duplicates-from-sorted-array/

**Description**: Remove duplicates in-place from a sorted array.

**Example**:
```
Input: nums = [1,1,2]
Output: 2, nums = [1,2,_]
```

**Topics**: Array, Two Pointers
