# Week 4: Markdown and Documentation

## Learning Objectives
- Master Markdown syntax
- Write professional READMEs
- Understand documentation importance in open source

## Easy Tasks
1. **Learn Markdown Basics**:
   - Headers (#, ##, ###)
   - Lists (ordered and unordered)
   - Links and images
   - Code blocks
   - Tables

2. **Create a Profile README**:
   - Create repo: `yourusername/yourusername`
   - Add README.md with: bio, skills, current learning
   - Add GitHub stats badges

3. **Improve Your Project READMEs**:
   - Add clear project description
   - Include installation instructions
   - Add usage examples
   - Include license information

4. **Practice**: Rewrite your journal.md with better formatting
